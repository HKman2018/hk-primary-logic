# 香港小學邏輯訓練 · 題型大綱（繁中）

對象：小四至小六｜MVP 五類｜硬約束：每日唔重複（對齊 `js/generators.js`：HKT 日期種子＋localStorage 已出題 id）

## 共用規格
- 題幹：短句、香港小學用語（阿明／小華、學校／公園；避免內地口語）
- 答法：`choice`（選項）或 `fill`（填數字／符號）
- 回饋：啱→「做得好」；錯→「再諗一諗」；可「睇提示」
- 每日每類 5 題；同日穩定、換日唔同；跨日避開已出 id
- 難度：每日 5 題內輪轉 P4／P5／P6（約 2+2+1 或 1+2+2）

## 1. 找規律／數列（pattern）
**練：** 找出重複或遞增規律並推下一步  
**參數化規則：** 固定加減、兩數／兩符號／三符號循環、差距遞增或遞減、兩條交錯數列、斐波那契式、×k、×k 再加、n×(n+k)、平方、差距循環（P4／P5／P6 各有獨立族）  
**樣本（參考 `js/questions.js`）：**  
1. P4 2、4、6、8、？→10（+2）  
2. P4 ○□○□○？→□  
3. P5 1、2、4、7、11、？→16（差距+1,+2,+3…）  
4. P5 3、6、5、10、9、18、？→17（×2 再 −1）  
5. P6 2、6、12、20、30、？→42（偶數差距）

## 2. 分類／歸類（classify）
**練：** 按屬性歸類、搵異類；P5+ 可兩屬性  
**參數化：** 預置「同類＋異類」包（水果／動物／文具／讀物／圓相關…），抽 4 項必含異類  
**樣本：**  
1. 蘋果、香蕉、橙、汽車→汽車  
2. 圓、球、環、正方形→正方形  
3. 要「紅色＋圓形」→紅圓形  
4. 貓狗｜麻雀金魚 分組  
5. 紙／布／膠紙／玻璃板→玻璃板（唔可摺）

## 3. 條件推理（condition）
**練：** 如果…就…／全部／有啲／只有…才…  
**參數化：** 模板＋人名洗牌；P4 一至兩條件；P5「有啲」≠全部、高低比較；P6 必要條件  
**樣本：** 下雨帶傘；全部有書包；有啲紅色水果；高矮鏈；打機⇒完成功課

## 4. 圖形／空間（spatial）
**練：** 對稱、旋轉、拼合、路徑、展開圖  
**參數化：** 等級模板庫＋日期種子抽選（靜態站用文字描述；日後可加 SVG）  
**樣本：** H 對稱；正方形轉 90°；路徑兩段；兩直角三角拼矩形；正方體六面

## 5. 真假／矛盾（truth）
**練：** 一真一假、矛盾句、三人恰一人假、連環指證  
**參數化：** 人名洗牌＋矛盾模板  
**樣本：** 食糖對立句→唔夠資料邊個假；全日雨 vs 無雨；恰一人假情境；「全部交功課」矛盾句；阿強／阿傑互指
